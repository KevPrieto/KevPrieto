## 🛫 Flight Fare Optimizer
**JavaFX desktop app** that loads flights from JSON, applies filters, ranks them by price, and exports clean PDF reports.

**Tech:** Java 17 · JavaFX · FXML · Jackson · iTextPDF · Streams API · Maven · JUnit 5

**Highlights**
- Classpath-safe JSON loading  
- Cheapest-flight detection using Streams  
- UTF-8 & €-safe PDF export with embedded fonts  
- Packaged with `jpackage`  
- JUnit-tested business logic.
